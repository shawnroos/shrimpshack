# Journal and sources

The journal logs every event and every prompt, with its origin. Sources are what a sweep reads: the terminal host (herdr, Rex or Ghostty), the issue tracker, each session's task list, and recent plan docs. A source can be turned off or marked unsupported.

- **Where it lives:** `lib/programme_journal.py`, `docs/contracts/programme-durability.md`
- **Note:** Only a typed prompt, or a pick of an approval label, counts as approval.
