# Behaviour

Shawn's standing guidance ("always X, never Y, when X do Y") with checks the PM can test. Behaviours live in layers (programme, repo, personal). The PM reminds a worker when a trigger fires, and sends work back that skips one.

- **Where it lives:** `docs/contracts/programme-behaviours-format.md`, `lib/programme_behaviours.py`
- **Note:** New or retired behaviours need Shawn's answer to an offer.
