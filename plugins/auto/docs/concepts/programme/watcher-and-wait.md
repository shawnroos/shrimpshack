# Watchers and waits

Every wait has a live watcher or a named reporter. The remit watcher prints one line for a change the PM must act on. Claude Code ends every Monitor after 30 minutes, and the PM re-arms it. A cron job is the fallback wake-up.

- **Where it lives:** `lib/programme-watch.sh`
- **Note:** Record with `set-waiting` and `watcher-beat`.
