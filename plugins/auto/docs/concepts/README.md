# Concepts

Auto has two layers. Auto runs one plan to done. A programme lets one PM session look after many items across a terminal space.

```
Auto (one run)                    Programme (one PM, many items)
  plan -> workflow -> backend       PM -> agreement -> remit -> items
  pulse + dispatcher                  items -> deliverables -> evidence
  run record -> exit predicate        rules, Rulings, behaviours, asks
```
